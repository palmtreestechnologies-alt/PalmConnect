# Palm Connect

The AI-powered hospitality connectivity platform that simplifies guest networking, cloud management, analytics, and intelligent automation.

## Project Structure

- `website/` - Marketing website (Next.js + React)
- `cloud/` - Palm Cloud backend (Supabase + PostgreSQL)
- `edge/` - Palm Edge Gateway (Go + SQLite)
- `ai/` - Palm AI integration (Claude API)
- `docs/` - Documentation

## Getting Started

See the relevant directory for setup instructions.

## Tech Stack

- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: Supabase (Postgres + Auth + RLS)
- **Edge**: Go, SQLite
- **AI**: Claude API (Anthropic)
- **Hosting**: Vercel, Supabase-managed Postgres
